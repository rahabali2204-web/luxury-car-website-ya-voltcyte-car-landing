# 🏎️ VoltCyte — Futuristic Luxury Hypercar Landing Page

A high-performance, interactive landing page for a modern electric luxury hypercar concept built with **React**, **Tailwind CSS**, and **Framer Motion**.[https://luxury-sports-car-la-cb15.bolt.host])https://luxury-sports-car-la-cbl5.bolt.host/#colors

![VoltCyte Preview](https://img.shields.io/badge/Status-Live-brightgreen) ![Tech Stack](https://img.shields.io/badge/Stack-React%20%7C%20Tailwind%20%7C%20Framer%20Motion-blue)

---

## ✨ Features

* **🏎️ Sleek Hero Section:** Dynamic title entrance with responsive glow effects.
* **🎨 Interactive Color Configurator:** Live color swatch switching to customize car aesthetics.
* **📊 Animated Performance Specs:** Scroll-triggered dynamic counters ($0\text{--}60\text{ mph}$ in $1.9\text{s}$, $1020\text{ HP}$, $400\text{ mi}$ range).
* **⚡ Modern Component Architecture:** Fully modular code using modern UI component standards.
* **📱 Fully Responsive:** Clean glassmorphism layout optimized across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React (Vite)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **Deployment:** Bolt.host / GitHub Pages

## 🚀 Quick Start (Local Setup)

Clone the project and install dependencies locally:

```bash
# Clone the repository
git clone [https://github.com/rahabali2204-web/luxury-car-website.git](https://github.com/rahabali2204-web/luxury-car-website.git)

# Navigate into the project folder
cd luxury-car-website

# Install packages
npm install

# Start local dev server
npm run dev
